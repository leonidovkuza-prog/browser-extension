# Deep Search для YouTube

Утилита цифровой гигиены для поисковой выдачи YouTube. Отсекает информационный шум (Shorts, стримы, кликбейт) и оставляет только длинный, нишевый и экспертный контент.

## 🚀 Что делает расширение

- **Скрывает Shorts** — как отдельные ролики, так и целые полки с ними.
- **Скрывает стримы и премьеры** (Live).
- **Фильтрует по длительности** — вы можете указать минимальное время видео (например, 20 минут).
- **Фильтрует по просмотрам** — отсекает вирусный контент, оставляя видео с малым числом просмотров (например, до 30 000).
- **Умная работа с SPA** — корректно работает при переходах по страницам YouTube без перезагрузки.
- **Презумпция невиновности** — если скрипт не смог распарсить данные, он *не скрывает* видео.

## 📦 Установка (Developer Mode)

Так как расширение не опубликовано в Chrome Web Store, его нужно установить вручную:

1. Скачайте этот репозиторий (нажмите зеленую кнопку **Code** -> **Download ZIP** и распакуйте, либо склонируйте через `git clone`).
2. Откройте браузер и перейдите по адресу `chrome://extensions/` (или `edge://extensions/`).
3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked).
5. Выберите папку с распакованным расширением (где находится `manifest.json`).
6. Откройте [поиск YouTube](https://www.youtube.com/results?search_query=test), нажмите на иконку расширения и включите режим.

## ⚙️ Настройки

Откройте попап расширения (клик по иконке):

- **Включить Deep Search Mode** — глобальный переключатель.
- **Скрывать Shorts** — прячет вертикальные видео.
- **Скрывать стримы** — прячет прямые эфиры.
- **Минимальная длительность (мин)** — видео короче этого времени будут скрыты. `0` = без ограничения.
- **Максимум просмотров** — видео с большим числом просмотров будут скрыты. `0` = без ограничения.

## 🛠️ Технические детали

- Написан на чистом Vanilla JS (ES6+) без сторонних зависимостей.
- Использует `MutationObserver` для синхронной обработки динамически подгружаемых элементов без мерцания.
- Агрессивный парсер текста (`textContent` + `aria-label`), устойчивый к изменениям верстки YouTube.
- Работает локально. Никакие данные не отправляются на серверы (используется только `chrome.storage.sync` для сохранения настроек).
